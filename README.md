# SHAeR

SHAeR is a local-first music and memory device: a Raspberry Pi powered audio companion with a small screen, themes, local music, Spotify integration, recordings, annotations, and phone/desktop companion apps.

This repository is the GitHub-ready SHAeR source tree. It includes:

- Native firmware and renderer source
- Raspberry Pi runtime server and backend modules
- Android/phone companion source and release artifact
- Desktop companion source with Tauri packaging
- Shared desktop contracts
- Release artifacts and checksums
- Documentation, build guides, and verification notes
- A download page for phone and desktop installers

## Downloads

Open the download page:

[Download SHAeR apps](docs/downloads.html)

Current included artifacts:

| Platform | File | Notes |
| --- | --- | --- |
| Android phone companion | `releases/SHAeR-Companion-0.17.0-debug.apk` | Existing debug APK artifact |
| Phone PWA bundle | `releases/shaer-companion-pwa-0.17.0.zip` | Installable web/PWA bundle |
| Raspberry Pi runtime | `releases/shaer-pi-runtime-0.16.0.tar.gz` | Pi runtime package |
| BLE bootstrap | `releases/shaer-ble-bootstrap-0.18.0.tar.gz` | BLE discovery/bootstrap package |
| Desktop Windows | Built by `.github/workflows/desktop-windows-release.yml` | Produces `.exe` and `.msi` on Windows runner |
| Desktop macOS | `apps/desktop/src-tauri/target/...` after local build | `.app` bundle, not committed by default |

Windows installers are generated by GitHub Actions on a Windows runner. Once a `.exe` or `.msi` is uploaded to a release, the download page can link to it and show a QR code.

## Desktop Companion

```bash
cd apps/desktop
npm ci --no-audit --no-fund
npm run typecheck
npm run test
npm run build
```

macOS app bundle:

```bash
. "$HOME/.cargo/env"
npm run tauri:build:app
```

Windows installer build runs on Windows:

```powershell
cd apps/desktop
npm ci --no-audit --no-fund
npm run tauri:build:windows
```

## App Icon

The current base icon is the red vinyl SHAeR Companion image. To update every packaged phone/desktop icon target from one PNG:

```bash
cd apps/desktop
npm run icon:update -- /absolute/path/to/icon.png
```

Then rebuild the Android APK and desktop installers.

## Publishing To GitHub

From this folder:

```bash
git init
git add .
git commit -m "Initial SHAeR public repository"
git branch -M main
git remote add origin https://github.com/<owner>/<repo>.git
git push -u origin main
```

After pushing, enable GitHub Actions and run `Desktop Windows Release` to generate Windows `.exe` and `.msi` artifacts.
