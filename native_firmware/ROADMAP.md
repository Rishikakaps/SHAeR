# SHAeR Roadmap

## V1 Alpha

- Track A Milestone 1: boot, 2.4" IPS TFT SPI display, EC11 navigation, SD-card MP3 browsing, PCM5102A playback, volume control, and safe shutdown.
- Track A Milestone 2: hardware diagnostics and breadboard verification.
- Track B begins only after the local playback prototype is stable.

## V1 Hardware Bring-Up

- Verify TFT display, input, MAX17048, PCM5102A, INMP441, Bluetooth, and Wi-Fi on the breadboard.
- Measure boot time, CPU, memory, and power budgets.
- Replace any placeholder command-line audio paths with measured hardware-backed implementations.

## V1 UI Polish

- UI framework.
- Theme engine.
- Individual themes: Archive Dark, Bombay Ticket, Windows-style, Indian Raga, Ghibli Garden, and Punk/alternate.
- Animations, transitions, and final assets.

## V1 Release Candidate

- Freeze database schemas.
- Freeze ThemeAPI v1.
- Validate firmware update rollback.
- Validate Safe Mode.
- Validate companion sync.

## V2 Direction

- Alternate DAC/display/battery modules.
- Richer Memory Mode.
- Asset compiler.
- Localization.
- More Bluetooth features.
